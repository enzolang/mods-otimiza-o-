# Mods de otimização

Pacotes para melhorar o desempenho de jogos no PC. Cada jogo tem a própria pasta, com os arquivos e um `LEIAME.md` explicando como instalar e como desfazer.

| Jogo | Pasta | O que melhora |
|---|---|---|
| Silent Hill 2 (Remake, 2024) | [`silent-hill-2-remake/`](silent-hill-2-remake/) | Travadas (*stutter*) ao andar pela cidade e guia de configurações para ganhar FPS |

## Antes de usar qualquer pacote

- Leia o `LEIAME.md` da pasta do jogo.
- Os scripts sempre fazem backup antes de alterar qualquer coisa, e cada pacote tem um jeito de desfazer.
- Os `.bat` são texto puro: dá para abrir no Bloco de Notas e conferir o que fazem antes de rodar.
